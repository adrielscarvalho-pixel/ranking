# Ranking 2001–2026

Filmes, séries, minisséries e documentários aprovados ao mesmo tempo por público e crítica (IMDb, Rotten Tomatoes e Metacritic), com onde assistir no Brasil.

Também é um diário pessoal: com uma conta, dá para marcar o que está vendo, dar nota, contar temporadas, anotar e compartilhar o perfil (login e dados no Supabase; a busca de títulos usa o TMDB por uma função no servidor).

Cartazes fornecidos pelo [TMDB](https://www.themoviedb.org/). Este site usa a API do TMDB, mas não é endossado nem certificado pelo TMDB.
